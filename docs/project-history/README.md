# Project history

These files preserve the repository's early design notes and research log. They are not a sample corpus or an end-user wiki. User sources and generated wiki pages live only in the ignored `.bropsy/` directory.

The early [problem framing](problem-framing.md) is also historical. Its open questions predate the confirmed architecture and should not be treated as current requirements. The original source manifest mentions `raw/private/`; that guidance is obsolete. Use ignored `sources/` for local input files and the `enqueue` command to acquire them.
